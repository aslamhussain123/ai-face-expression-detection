# Next.js Face Detection App

A simple real-time face detection app using Next.js, TypeScript, Material UI, and TensorFlow.js (BlazeFace).

## 🚀 How to Run
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## 🧠 Features
- Uses TensorFlow BlazeFace for real-time face detection.
- Material UI for styling.
- Webcam streaming and face box overlay.
